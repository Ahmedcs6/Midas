# Midas

## Overview

Midas is a social media backend built with ASP.NET Core Web API. It allows users to manage their accounts, share content, and interact with other users.

## Core Features

- User registration and authentication.
- Email confirmation and password recovery.
- User profiles and privacy settings.
- Public and private accounts.
- Follow relationships and follow requests.
- Posts and media attachments.
- Comments and reactions.
- Notifications.
- Session and token management.

## Technology Stack

- **Framework:** ASP.NET Core Web API (.NET 10)
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Authentication:** ASP.NET Core Identity and JWT

## Goals

- Build a maintainable backend with clear separation of responsibilities.
- Apply appropriate architecture and design principles.
- Implement authentication, authorization, and privacy controls securely.
- Write automated tests for important business rules.
- Provide clear API documentation and setup instructions.

## Scope

The initial scope focuses on the core social-media features listed above. Detailed requirements, business rules, and implementation decisions will be documented as needed during planning and development.
